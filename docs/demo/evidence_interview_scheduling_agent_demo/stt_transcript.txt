A scripted scheduler for Tola Aurora, a fictional hiring co-op. A slot books only after the candidate confirms that exact slot, offline, no key. Candidate one asks for Ana Luz on April 14th, 2026, Buenos Aires time. Three options. Candidate confirms option one, 09:00. Hold, then book on the internal calendar. The invite email stays pending_approval. Nothing was sent yet. A simulated recruiter approves that same call. Outbox one, booked one, terminal completed. An approval of 10:00 would not cover eleven. The hash binds tool and arguments. The expensive mistakes are a wrong slot and an invite that leaves before anyone approves, not covered, a real calendar, an authenticated recruiter channel, or live model quality. Live mode on this revision is u n v r, run python-m scheduling_agent demo, lab path cost zero.
